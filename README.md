# Golden Group HTML Exercise

A small group coursework repository containing a basic HTML page.

The page records a short member list. There is no application framework, dependency installation, or server component.

## Start reading

- [`hello_world.html`](hello_world.html)

## View locally

Serve the repository directory with a local static server, for example:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [hello_world.html](http://127.0.0.1:8000/hello_world.html). Any CDN libraries, hosted APIs, or map providers referenced by the page still require network access.
